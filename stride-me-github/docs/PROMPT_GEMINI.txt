- J'ai un fichier FIREBASE-A-COLLER.txt avec le bloc de règles Firestore à coller : tu ne dois PAS inventer d'autres règles. Quand on arrivera à cette étape, je te collerai le contenu du fichier si tu en as besoin.

LES ÉTAPES À ME FAIRE FAIRE, DANS CET ORDRE
1. Firebase : ouvrir/créer le projet, vérifier la config web (apiKey, authDomain, projectId...) dans js/firebase-config.js.
2. Firebase > Authentication : activer E-mail/Mot de passe.
3. Firebase > Firestore : créer la base en mode production, région europe-west1 ou eur3.
4. Firestore > Règles : coller le BLOC 1 de FIREBASE-A-COLLER.txt puis Publier.
5. (Facultatif) Storage pour les photos : demande le plan Blaze, je peux m'en passer.
6. GitHub : créer un dépôt public "stride-me", dézipper le zip, envoyer le CONTENU du dossier (index.html doit être à la racine du dépôt) via Add file > Upload files, puis Commit.
7. GitHub > Settings > Pages : Deploy from a branch, main, / (root). Récupérer l'adresse https://MONPSEUDO.github.io/stride-me/
8. Firebase > Authentication > Paramètres > Domaines autorisés : ajouter MONPSEUDO.github.io.
9. Test : ouvrir l'adresse, créer un compte, importer le programme avec le code de séance 2008 (Planning > Séances > Code de séance), lancer une séance.
10. Me déclarer administrateur : copier mon UID (Authentication > Utilisateurs), créer dans Firestore la collection "admins", document = mon UID, champ since (string) = 2026. Puis Profil > Espace administrateur et créer mon code (6 caractères minimum).
11. Inviter les autres : envoyer l'adresse, "Ajouter à l'écran d'accueil" sur téléphone.
